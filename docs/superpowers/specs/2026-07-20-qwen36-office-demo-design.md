# Qwen3.6 35B Excel / PowerPoint 시연 설계

## 목표

Qwen3.6 35B와 Windows용 Excel·PowerPoint Add-in을 사용해 실제 업무 자동화를
시각적으로 시연한다. 각 시연은 사용자가 실행을 시작한 시점부터 결과 파일이 저장될
때까지 50초를 넘지 않아야 한다. 대상 Windows PC에는 Python이나 시스템 Node.js를
별도로 설치하지 않는다.

## 공통 성능 원칙

- Add-in 연결 시 기존의 CLI 선초기화를 사용한다.
- 시연 프롬프트는 짧고 결과 스키마와 작업 범위를 고정한다.
- 한 시연에서 Qwen 호출은 한 번의 세션 흐름으로 제한한다.
- 모델 출력 오류를 고치기 위한 추가 모델 호출은 하지 않는다.
- 45초에 실행을 중단하고 단계와 원인을 표시하여 50초를 넘지 않게 한다.
- cold 1회와 같은 세션의 warm 3회를 측정하며, 네 번 모두 50초 이내여야 합격이다.
- 입력, 프롬프트, 원시 이벤트, 결과 파일, 해시와 검증 결과를 단계별로 보존한다.

## Excel 시연

### 시나리오

법인카드 비용 정산 담당자가 한 달치 원천자료를 열고 Add-in에 자동 점검과 집계를
요청한다. Qwen이 36건 전체의 검토 수식을 채우고, 예외를 분류하며, 부서별 집계와
요약 화면을 완성한다. 비어 있던 표와 차트가 한 번에 채워져 자동화 전후가 명확히
보여야 한다.

### 테스트 자료

`원천자료` 시트에 36건을 미리 제공한다. 열은 거래일, 카드번호 마스킹값, 부서,
사용자, 가맹점, 비용구분, 금액, 영수증 상태, 승인 한도, 검토결과로 구성한다.
부서는 네 개이며 정상 28건과 다음 예외 8건을 포함한다.

- 영수증 미첨부 3건
- 승인 한도 초과 3건
- 동일 날짜·사용자·가맹점·금액의 중복 의심 2건

`자동화결과` 시트에는 제목, KPI 위치, 부서별 표와 차트 틀만 미리 배치한다. 결과
값과 원천자료의 검토결과 열은 비워 둔다. 차트는 결과 표를 참조하여 Qwen이 수식과
집계를 입력하는 즉시 갱신되게 한다.

### Qwen 작업 범위

- 원천자료 전체를 한 번 읽는다.
- 검토결과 열에 정상, 영수증 누락, 한도 초과, 중복 의심 수식을 일괄 입력한다.
- 자동화결과에 총 사용액, 정상 건수, 예외 건수와 예외 금액을 수식으로 입력한다.
- 네 부서의 사용액과 예외 건수를 `SUMIF`/`COUNTIF` 계열 수식으로 집계한다.
- 제목, KPI, 헤더, 금액과 예외 영역에 제한된 서식을 적용한다.
- 설명문을 길게 출력하지 않고 결과 완료만 알린다.

Add-in에 차트 생성 도구가 없으므로 차트 개체는 테스트 workbook에 미리 존재해야
한다. Qwen은 차트의 원천 셀을 완성한다.

## PowerPoint 시연

### 사용자 흐름

사용자는 A4 한 페이지 제출양식용 PPTX를 활성 템플릿으로 선택한다. 이후 Markdown이
아닌 줄글 회의록을 붙여넣고 `/template-report`를 실행한다. Qwen은 회의록을 한 번에
구조화하고 Add-in의 로컬 PowerPoint 엔진은 템플릿을 복제·채워 1~3페이지 PPTX를
생성한다.

### 템플릿 계약

지원 템플릿은 A4 세로 한 페이지이며 다음 특징을 가진다.

- 로고, 헤더와 푸터
- 제목, 작성일과 사업부 영역
- 중제목으로 구분된 여러 본문 영역
- 선택적인 한 개의 표 영역

도형 ID와 정확한 좌표는 고정하지 않는다. 텍스트 표식, 도형 종류, 상대 위치와 표
구조를 조합해 슬롯을 찾는다. 실제 템플릿의 제목 위치, 중제목 문구, 표 크기와 로고가
조금 달라도 같은 계약을 만족하면 처리한다.

### 입력과 구조화

PowerPoint task pane은 최대 10MB의 `.pptx`를 로컬 바이너리 첨부로 허용한다. 템플릿
내용을 모델 프롬프트에 포함하지 않고 인증된 localhost WebSocket을 통해 sidecar의
작업 폴더에 저장한다. 파일명, 크기, ZIP 서명과 PowerPoint 열기 가능 여부를 검사하며
작업 폴더 밖 경로는 허용하지 않는다.

Qwen3.6 35B는 붙여넣은 회의록을 다음 고정 스키마로 변환한다.

- 제목, 일자, 사업부
- 순서가 보존된 중제목과 요약 문장 또는 불릿
- 실행 과제: 과제, 담당자, 기한, 상태
- 리스크와 승인 요청

모델 출력은 사용자 화면에 원시 JSON으로 표시하지 않는다. JSON 파싱이 실패하면 추가
모델 호출 없이 로컬 문장 분할 폴백으로 제목, 단락과 날짜를 구성한다.

### 템플릿 채우기와 페이지 분할

템플릿 원본은 수정하지 않고 복사본을 사용한다. 로고, 헤더, 푸터와 템플릿 서식은
불변 영역으로 취급한다. 본문은 템플릿의 글꼴 크기를 유지하며 다음 규칙으로 1~3장에
배치한다.

- 중제목과 해당 단락의 첫 본문은 같은 페이지에 둔다.
- 표의 한 행은 페이지 사이에서 나누지 않는다.
- 공간이 부족하면 글꼴을 과도하게 줄이지 않고 템플릿 슬라이드를 복제한다.
- 복제 페이지에도 헤더, 푸터, 로고와 페이지 번호를 유지한다.
- 짧은 입력은 1장, 보통 입력은 2장, 긴 입력은 3장이 되도록 용량을 계산한다.
- 3장을 넘는 내용은 구조화 단계의 중요도와 실행 가능성을 기준으로 압축한다.

결과는 Add-in 작업 폴더의 `reports` 아래에 고유한 `.pptx`로 저장한다. PDF는 만들지
않는다.

## 오류 처리

- 템플릿이 계약과 맞지 않으면 찾지 못한 슬롯을 한국어 오류로 표시한다.
- 템플릿 파일이 너무 크거나 유효한 PPTX가 아니면 모델 호출 전에 거부한다.
- `원신한` 등 템플릿 글꼴은 유지하며 설치되지 않은 글꼴은 생성 전에 표시한다.
- PowerPoint 파일 잠금 또는 COM 오류는 임시 파일을 정리하고 재시도 없이 종료한다.
- 모델 구조화 실패는 로컬 폴백을 한 번 사용한다.
- 45초 제한에 도달하면 실행 단계와 로그 경로를 표시하고 종료한다.

## 테스트 및 합격 기준

### Excel

- 36건과 8건의 예외가 정확히 보존된다.
- 검토결과, KPI, 부서별 사용액과 예외 건수가 기대값과 일치한다.
- 결과 workbook을 Excel로 저장하고 재열 수 있다.
- 수식 오류가 없고 표·차트·핵심 수치가 잘리지 않는다.
- Qwen3.6 35B cold 1회와 warm 3회가 각각 50초 이내다.

### PowerPoint

- 짧은, 보통, 긴 줄글 회의록이 각각 1, 2, 3페이지를 생성한다.
- 제공된 `template.pptx`와 제목·중제목 위치가 다른 변형 템플릿을 모두 검사한다.
- 로고, 색상, 글꼴, 헤더와 푸터가 유지된다.
- 필수 제목, 날짜, 담당자, 실행 과제와 승인 요청이 결과에 존재한다.
- 모든 PPTX를 실제 PowerPoint로 재열 수 있다.
- 슬라이드 밖 개체, 텍스트 overflow, 잘림과 의도하지 않은 겹침이 없다.
- Qwen3.6 35B cold 1회와 warm 3회가 각각 50초 이내다.

- Excel 원천자료·빈 결과 틀 workbook
- Excel 시연 프롬프트와 정답 oracle
- 짧은/보통/긴 줄글 회의록
- 템플릿 변형 테스트 파일
- PowerPoint 시연 프롬프트
- 실제 Excel 결과 workbook과 1~3페이지 PPTX
- cold/warm 성능 지표, 원시 이벤트, Office 재열기·시각 검증 결과와 파일 해시
